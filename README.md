# Cloud Security Lab

## Overview

This project demonstrates basic cloud security concepts using a controlled lab environment. The objective is to identify common cloud security risks, document secure configuration practices, and create practical remediation guidance.

## Objectives

- Understand core cloud security concepts
- Review identity and access management controls
- Document secure storage configuration
- Analyze cloud logging and monitoring practices
- Identify common cloud misconfigurations
- Create security-focused documentation for portfolio use

## Planned Lab Focus Areas

| Area | Description |
|---|---|
| Identity and Access Management | Review users, roles, permissions, and least privilege |
| Storage Security | Analyze public access risks and secure storage settings |
| Logging and Monitoring | Review cloud activity logs and detection opportunities |
| Network Security | Review inbound access, ports, and segmentation |
| Secure Configuration | Document cloud hardening recommendations |
