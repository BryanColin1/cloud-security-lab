# Cloud Security Lab Scope

## Purpose

This lab demonstrates basic cloud security assessment and secure configuration practices in a controlled cloud environment. The goal is to understand common cloud risks and document practical remediation guidance.

## Environment

This lab is performed using a personal cloud lab environment created for educational purposes.

## In Scope

- Identity and access management review
- Least privilege analysis
- Storage access configuration
- Network security rules
- Cloud logging and monitoring review
- Security documentation and remediation planning

## Out of Scope

- Third-party cloud environments
- Production systems
- Unauthorized testing
- Denial-of-service testing
- Credential attacks
- Accessing or storing sensitive real-world data

## Rules of Engagement

- Only use cloud resources owned or controlled by me
- Do not expose sensitive data
- Do not upload secrets, keys, tokens, or credentials to GitHub
- Remove test resources when no longer needed
- Use screenshots only after confirming no sensitive information is visible
